# Helpdesk Checklist

A simple checklist for handling common IT support requests.

## 1. Understand the Issue

- Ask the user what problem they are facing
- Note the device, operating system, and application involved
- Ask when the issue started
- Check whether the issue affects one user or many users

## 2. Basic Troubleshooting

- Restart the application
- Restart the computer if needed
- Check cables, power, Wi-Fi, and network connection
- Confirm the user has the correct login or permissions
- Look for error messages and record them clearly

## 3. Windows Support Checks

- Check Task Manager for frozen applications
- Review available storage space
- Run Windows Update when appropriate
- Check Device Manager for driver problems
- Confirm printer and network settings

## 4. Documentation

- Write the issue in simple words
- Record the steps already tried
- Add the final solution
- Mention if the issue needs escalation

## 5. Escalation

Escalate the issue when it involves server access, security concerns, repeated failure, or a problem outside your permission level.
